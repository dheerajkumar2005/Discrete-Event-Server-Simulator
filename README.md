**Contents**
- simulator.hh: header file for the simulator contains classes for Request, User, Server, Metrics
- simulator.cc: source file for the simulator classes 
- main.cc: contains core simulation logic, generates metrics.csv
- tandem_simulator.hh : extension of simulator.hh for 2-server tandem queuing
- tandem_simulator.cc : extension of simulator.cc for 2-server tandem queuing
- tandem_main.cc : extension of main.cc for 2-server tandem queuing
- plot.py: plot functions for plotting metrics, takes one metrics.csv
- plot_all.py ;  plot functions for plotting metrics, takes multiple metrics.csv and produces plots on top of each other
- plot_tandem.py: plot functions for plotting metrics, takes one metrics.csv for tandem queues
- metrics.csv: example output generated by main.cc
- config.txt: contains structure of input
- tandem_config.txt: extension of config.txt for tandem queue
- Report.pdf : assignment report


**Usage**
- `g++ simulator.cc main.cc -o sim` : compilation
- `Fill the configuration file`
- `./sim` : needs config.txt to be in the same directory as sim, produces metrics.csv
- `python3 plot.py <path to metrics.csv> <output directory>` : produces metrics graphs
- `python3 plot_all.py <output directory> <path to metrics1.csv> <path to metrics2.csv> ...` : produces plots for different configs on top of each other for comparison
